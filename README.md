# CartPulse

CartPulse is a mobile shopping assistant for keeping a running grocery total while you shop. The core flow is simple: set a spending limit, add items to the cart, see the running total and remaining budget, and review the cart before checkout.

> **Current status:** The repository is an Expo starter project. The product screens in the supplied design files are not implemented in the repository yet.

## Quick start

### Requirements

- Node.js
- npm
- Expo Go or an Android/iOS development environment

### Install

```bash
npm install
```

### Start

```bash
npm start
```

Then use the Expo CLI to open the project on a device, emulator, simulator, or web.
